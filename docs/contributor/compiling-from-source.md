# Compiling Resurrection Capsule from source

> [!NOTE]
> This page is under construction. All content within is subject to change, and might not be accurate.

# Prerequisites
- Operating system and Darkspore version listed in the Prerequisites section of [Getting started](/docs/user/getting-started.md).
- [.NET 6 SDK](https://dotnet.microsoft.com/download/dotnet/6.0) (Hub)
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) (Server)

### How to compile

1. `git clone --recursive https://github.com/Resurrection-Capsule/ReCap`
2. `cd ReCap/ReCap.Server`
3. `dotnet build`
